# 交作业 📚

这里是每周「做饭作业」的记录仓库。规则很简单：

## 怎么交作业

1. **每周一道菜**：从 [recipes/_index.md](../recipes/_index.md) 按顺序选，或自由发挥
2. **复制模板**：	emplates/weekly-template.md → week-XX.md（XX 是周数，如 week-36.md）
3. **填内容**：做了啥、食材、过程、翻车点、心得
4. **放照片**：成品图放到 ssets/week-XX/，在作业里引用
5. **提交**：commit + push，完成一次作业

> 作业文件命名：week-<周数>.md，示例：week-36.md
