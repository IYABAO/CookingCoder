# 可乐鸡翅

> 零失败的甜咸口味，小朋友的最爱，新手也能端出硬菜。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 鸡翅中 | 10个 | 两面划刀 |
| 可乐 | 1罐 | 330ml |
| 姜 | 3片 |  |
| 生抽 | 2勺 |  |

## 步骤

**焯水**：鸡翅冷水下锅加料酒焯去浮沫，捞出控干。
**煎翅**：热油下鸡翅煎至两面金黄。
**焖煮**：加姜片、生抽、倒入可乐没过鸡翅，烧开转中小火焖 15 分钟。
**收汁**：大火收汁至浓稠挂翅，撒芝麻葱花。

## 要点（翻车预警）

- 用无糖可乐会更好吃，甜度更清爽。
- 收汁勤翻动，防糊。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：咸甜，食材本味突出
