# 油焖大虾

> 红亮油润、虾肉弹嫩，宴客最有面子的快手硬菜。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 大虾 | 500g | 开背去虾线 |
| 姜 | 3片 | 切丝 |
| 葱 | 2根 | 切段 |
| 糖 | 1勺 |  |

## 步骤

**处理虾**：大虾开背去虾线，擦干水分。
**煎虾**：热油下虾煎至两面变红，用铲子压出虾油。
**焖制**：加姜葱、2 勺生抽、1 勺料酒、1 勺糖、半碗水，盖盖焖 3 分钟。
**收汁**：大火收汁至汤汁裹满虾身，出锅。

## 要点（翻车预警）

- 压出虾头虾油是鲜味关键。
- 不要加太多水，收汁要浓。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：咸甜，食材本味突出
