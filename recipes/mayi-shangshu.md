# 麻婆豆腐

> 川菜的 `main()` 函数——麻、辣、烫、嫩、酥、香、鲜七味参数一次性传入，烧一锅就能跑通。

## 常量定义（Constants）

| 常量名 | 值 | 来源 |
| --- | --- | --- |
| FIRE_MEDIUM | 中火(160-180℃，火焰舔锅底一半) | _spec §3 |
| FIRE_LOW | 小火(120-140℃，火焰不舔锅底) | _spec §3 |
| OIL_60 | 五六成热(120-160℃，竹筷快速冒细泡) | _spec §4 |
| SOY_SAUCE | 1勺(15ml，汤勺) | _spec §2 |
| COOKING_WINE | 1勺(15ml，汤勺) | _spec §2 |
| SUGAR | 半小勺(2.5ml) | _spec §2 |
| SALT | 半小勺(2.5ml) | _spec §2 |
| STARCH_WATER | 淀粉:水=1:3 | _spec §6 |
| SIMMER_TIME | 3-5min | — |

## 食材清单（Input）

| 食材 | 用量 | 切配规格 | 备注 |
| --- | --- | --- | --- |
| 嫩豆腐 | 1盒(约400g) | 切块(2cm见方，骰子大) | _spec §1，选内酯豆腐更嫩 |
| 牛肉末 | 100g | 剁细(<2mm，细沙) | 没有牛肉用猪肉末 |
| 郫县豆瓣酱 | 1大勺(15ml，火锅勺) | 剁细 | 必须剁细否则有硬皮 |
| 豆豉 | 1小勺(5ml) | 剁细 | 可选，增香 |
| 花椒粉 | 1小勺(5ml) | — | 出锅前撒，麻味来源 |
| 干辣椒面 | 1小勺(5ml) | — | 可选，增加辣度和红色 |
| 蒜苗 | 2根 | 切粒(5mm，米粒) | _spec §1，没有用葱花 |
| 蒜 | 3瓣 | 切末(<2mm，细沙) | _spec §1 |
| 姜 | 1小块 | 切末(<2mm) | _spec §1 |
| 生抽 | 1勺(15ml) | — | 提鲜 |
| 淀粉 | 1大勺(15ml) | 调水淀粉 | _spec §2 |

## 预处理（Preprocess）

- **豆腐焯水（内存预热）**：锅中加水烧开，加 SALT(半小勺盐)，下豆腐块焯 1min 捞出沥干——这一步去除豆腥味并让豆腐定型，烧的时候不易碎。相当于给变量做初始化，避免运行时 null 异常。
- 豆瓣酱、豆豉分别剁细；蒜末、姜末、蒜苗粒备好。
- 调 STARCH_WATER(水淀粉)：淀粉1大勺+水3大勺搅匀备用。

## 主流程（Main Logic）

1. **炒肉末（数据写入）**：热锅倒油，油温 OIL_60(五六成热)，下牛肉末中火煸炒至酥香变色（约 2min），盛出备用。`if 肉末结块: 用锅铲压散`，结块就是未序列化的数据。

2. **炒底料（依赖加载）**：锅留底油，转 FIRE_LOW(小火)，下剁细的豆瓣酱炒出红油（约 1min），再下蒜末、姜末、豆豉炒香——底料是这道菜的核心库，必须小火慢炒出香，大火会糊。

3. **烧豆腐（while 循环）**：加入 COOKING_WINE(1勺料酒)、SOY_SAUCE(1勺生抽)、SUGAR(半小勺糖)，加 1碗(250ml)清水或高汤，放入豆腐块和炒好的肉末，转 FIRE_MEDIUM(中火)烧开。`while 汤汁微沸: 保持 3-5min`，期间用锅铲背轻推（不要翻炒，豆腐易碎），让豆腐充分吸味——这是一个保持微沸状态的循环，终态是豆腐内部入味。

4. **勾芡（函数包装返回值）**：调用 `_spec §6 勾芡()`——分两次淋入 STARCH_WATER(水淀粉)，第一次淋入后轻推至汤汁变稠，再补第二次，边淋边推至汤汁浓稠可挂勺挂糊(_spec §5)。分两次勾芡是关键，一次到位容易结块，就像分批提交事务比一次性大事务更安全。

5. **出锅（装饰器模式）**：撒上花椒粉(1小勺)、蒜苗粒(或葱花)，可选撒干辣椒面，推匀立即出锅。花椒面和蒜苗是出锅前的装饰器——不参与主流程计算，但在返回前包裹一层，瞬间提升风味层级。

## 翻车预警（Bug Report）

- ⚠️ **Bug: 豆腐碎成渣** → 根因：翻炒用力过猛 or 未焯水定型 or 水太少烧干。修复：焯水加盐定型、用锅铲背轻推而非翻炒、保证汤汁没过豆腐一半。
- ⚠️ **Bug: 味道发苦** → 根因：豆瓣酱炒糊了 or 花椒粉下锅太早。修复：FIRE_LOW(小火)炒豆瓣酱至刚出红油即可、花椒粉必须出锅前撒。
- ⚠️ **Bug: 汤汁太稀不挂糊** → 根因：水淀粉比例不对 or 一次倒太多淀粉结块。修复：严格 STARCH_WATER=1:3、分两次淋入、边淋边推。
