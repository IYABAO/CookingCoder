# 干煸四季豆

> 干煸到虎皮状的四季豆，干香入味，越嚼越香。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 四季豆 | 400g | 去筋掰段 |
| 干辣椒 | 6个 | 剪段 |
| 花椒 | 1小把 |  |
| 肉末 | 80g | 可选 |
| 蒜 | 4瓣 | 切末 |

## 步骤

**煸豆**：锅下较多油，中小火将四季豆煸至表皮起皱发虎皮，盛出。
**炒料**：留底油下肉末炒酥，加干辣椒花椒蒜末炒香。
**合炒**：倒回四季豆，加盐、生抽、少许糖，大火翻炒。

## 要点（翻车预警）

- 四季豆一定要煸透/炒熟，生食有毒！
- 中小火耐心煸，才出虎皮效果。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：干香，食材本味突出
