# 番茄炖牛腩

> 番茄的酸甜炖进软烂的牛腩，汤都能拌三碗饭。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 牛腩 | 600g | 切块 |
| 番茄 | 4个 | 2个切块2个打成泥 |
| 洋葱 | 半个 | 切块 |
| 姜 | 4片 |  |

## 步骤

**焯水**：牛腩冷水下锅焯透洗净。
**炒番茄**：热油炒洋葱、番茄块至软烂出沙，加番茄泥增色。
**炖煮**：下牛腩，加开水、生抽、姜片，小火炖 70 分钟。
**收浓**：大火收浓汤汁，补盐调味出锅。

## 要点（翻车预警）

- 番茄一半切块一半打泥，汤汁才浓郁。
- 炖够时间，牛腩软烂。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：酸甜，食材本味突出
