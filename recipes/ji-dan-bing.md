# 家常鸡蛋饼

> 十分钟搞定的早餐主食，软嫩咸香，配粥配奶都合适。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 面粉 | 100g |  |
| 鸡蛋 | 2个 |  |
| 葱花 | 适量 |  |
| 水 | 150ml | 调糊用 |

## 步骤

**调糊**：面粉加水搅成无颗粒糊，打入鸡蛋、葱花、盐拌匀。
**摊饼**：平底锅刷油，倒一勺面糊转圈摊平。
**翻面**：小火煎至底面定型翻面，两面金黄出锅。

## 要点（翻车预警）

- 面糊要稀一点，饼才软。
- 全程小火，避免外糊里生。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：咸香，食材本味突出
