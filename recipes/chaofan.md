# 扬州炒饭

> 粒粒分明的黄金炒饭，清空冰箱剩菜的完美方案。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 隔夜米饭 | 1碗 | 最好隔夜 |
| 鸡蛋 | 2个 |  |
| 火腿/虾仁 | 50g | 切丁 |
| 青豆玉米 | 30g | 可选 |
| 葱花 | 适量 |  |

## 步骤

**备料**：米饭提前打散，鸡蛋打散，配料切丁。
**炒蛋**：热油炒蛋至半凝固，盛出。
**炒饭**：再加油下米饭炒散，中火炒至粒粒分明。
**合炒**：加配料、鸡蛋、盐、生抽，大火翻炒，撒葱花出锅。

## 要点（翻车预警）

- 隔夜饭 + 打散 + 大火，才能粒粒分明。
- 油不要太多，蛋液先裹饭更香。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：咸香，食材本味突出
