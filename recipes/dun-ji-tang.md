# 香菇炖鸡汤

> 一锅清甜滋补的鸡汤，温暖整个周末。

## 食材清单

| 食材 | 用量 | 备注 |
| --- | --- | --- |
| 土鸡 | 半只 | 斩块 |
| 干香菇 | 8朵 | 提前泡发 |
| 红枣 | 5颗 |  |
| 枸杞 | 1把 | 最后放 |
| 姜 | 4片 |  |

## 步骤

**焯水**：鸡块冷水下锅焯透，温水洗净。
**炖煮**：鸡块、香菇、红枣、姜片加开水，大火烧开转小火炖 50 分钟。
**调味**：出锅前放枸杞，加盐调味即可（鸡汤别太咸）。

## 要点（翻车预警）

- 干香菇泡发水可以一起炖，更香。
- 盐最后放，肉才不柴。

## 完成标准

- 视觉：色泽自然、形态完整
- 口感：鲜美，食材本味突出
