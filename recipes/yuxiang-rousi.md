# 鱼香肉丝

> 没有鱼却有鱼香味——这就是编程里的「鸭子类型」：走起来像鱼、叫起来像鱼，那它就是鱼香。

## 常量定义（Constants）

| 常量名 | 值 | 来源 |
| --- | --- | --- |
| FIRE_HIGH | 大火(200℃+，火焰包住锅底) | _spec §3 |
| OIL_60 | 五六成热(120-160℃，竹筷快速冒细泡) | _spec §4 |
| SOY_SAUCE | 1勺(15ml，汤勺) | _spec §2 |
| VINEGAR | 1勺(15ml，汤勺) | _spec §2 |
| SUGAR | 1勺(15ml，汤勺) | _spec §2 |
| COOKING_WINE | 半勺(7.5ml，半汤勺) | _spec §2 |
| SALT | 半小勺(2.5ml) | _spec §2 |
| STARCH | 1小勺(5ml) | _spec §2 |
| MARINATE_TIME | 10min | — |

## 预处理（Preprocess）

- **腌肉（编译期优化）**：肉丝中加入 SOY_SAUCE(半勺生抽)、COOKING_WINE(半勺料酒)、STARCH(1小勺淀粉)，抓匀至表面起黏，腌制 MARINATE_TIME(10min)。
- **配鱼香汁（预编译正则）**：碗中加入生抽1勺、醋1勺、糖1勺、SALT(半小勺盐)、淀粉1小勺、清水2勺(30ml)，搅匀备用——鱼香汁是这道菜的「预编译表达式」，所有参数提前配好，下锅时一次性调用，避免边炒边加导致火候失控。
- 泡椒末、泡姜末、蒜末、葱粒备好；木耳丝、胡萝卜丝、青椒丝、冬笋丝备好。

## 主流程（Main Logic）

1. **滑肉（数组遍历）**：热锅倒油，油温 OIL_60(五六成热)，下肉丝快速滑散——`for each 肉丝 in 锅: 均匀受热`，粘连就是未初始化的 bug。滑至变色（约 30s），盛出备用。

2. **炒底料（依赖注入）**：锅留底油，转 FIRE_HIGH(大火)，下泡椒末、泡姜末、蒜末爆香（约 20s）——泡椒和泡姜是鱼香味的「依赖注入容器」，提供酸、辣、咸的基础风味，没有它们就没有鱼香味。

3. **炒配菜（管道处理）**：下胡萝卜丝、木耳丝、冬笋丝，大火快炒 30s，再下青椒丝炒 10s——配菜按硬度排序依次入锅，就像 pipeline 中数据按处理时长分级进入，硬的先炒、软的后下，保证同步断生(_spec §5)。

4. **合炒+烹汁（函数调用）**：倒入滑好的肉丝，翻炒均匀，立即倒入提前配好的鱼香汁——`调用 鱼香汁()`，大火快速翻炒 20s 让汤汁浓稠挂糊(_spec §5)。鱼香汁入锅后不要久炒，淀粉糊化挂糊即止，久炒肉丝会老。

5. **出锅（返回值）**：撒葱粒，翻匀装盘。

## 翻车预警（Bug Report）

- ⚠️ **Bug: 没有鱼香味** → 根因：没放泡椒/泡姜 or 醋糖比例不对。修复：泡椒是鱼香味的核心依赖不可省略、醋:糖=1:1、提前配鱼香汁不要边炒边加。
- ⚠️ **Bug: 肉丝发柴** → 根因：顺纹切 or 未腌淀粉 or 炒太久。修复：逆纹切丝(_spec §1)、淀粉腌制、滑肉变色即盛出、合炒不超过 30s。
- ⚠️ **Bug: 汤汁太稀或太稠** → 根因：鱼香汁淀粉比例不对 or 翻炒时间不够/太久。修复：淀粉1小勺+清水2勺的比例、入锅后大火快炒 20s 至挂糊即止。
