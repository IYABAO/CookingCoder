# 水煮肉片



> 📐 **度量标准**：本菜谱所有模糊表述（块/勺/火候/油温/熟度）均以[_spec.md（度量标准库）](_spec.md) 为准，可点击各章节锚点查看。
> 川菜里的「事件驱动架构」——汤底(事件总线)煮沸→肉片(事件消费者)入锅→泼油(事件触发)瞬间激活麻辣香气，30 分钟完成一次高并发风味分发。

## 预处理（Preprocess）

- **腌肉（编译期优化）**：肉片加入 SOY_SAUCE(半勺生抽)、COOKING_WINE(半勺料酒)、SALT(半小勺盐)、STARCH(1小勺淀粉)、EGG_WHITE(半个蛋清)，抓匀至肉片表面起黏，腌制 MARINATE_TIME(15min)。淀粉+蛋清在肉表面形成**保护膜**——这就是「编译期优化」，下锅后肉纤维不会因高温急速失水，保持嫩滑。
- 豆芽去根洗净，干辣椒切段，蒜姜切末，所有 Input 就绪。

## 主流程（Main Logic）

1. **焯豆芽（初始化底层数据）**：烧一锅开水，加少许盐，下豆芽焯 30s 捞出，铺在碗底垫底。豆芽是这道菜的**底层数据结构**——承载上层肉片和汤汁，提供脆爽口感的 contrast。

2. **炒底料（构建事件总线）**：热锅倒油，油温 OIL_60(五六成热)，下 DOUBAJIANG(1大勺郫县豆瓣酱)小火炒出红油，加入姜末、一半蒜末炒香。这一步是在**构建事件总线**——豆瓣酱的红油和麻辣香气是后续所有风味事件的传输通道。炒至红油亮、酱香出（约 2min）。

3. **煮汤（事件总线预热）**：倒入 BROTH_BOWL(2碗清水/高汤)，加入 SOY_SAUCE(半勺生抽)、SALT(半小勺盐)，FIRE_HIGH(大火)烧开。汤底就是**预热完成的事件总线**，等待事件消费者(肉片)接入。

4. **下肉片（事件消费者接入）**：汤底煮沸后，将腌好的肉片逐片下入——这就像**事件消费者逐个注册到总线上**，不要一次性倒入（会粘连成坨，相当于消息堆积）。用筷子轻轻拨散，`while 肉片未变色: 轻推; 一旦变色浮起: 立即捞出`。肉片煮至变色（约 1-2min），连汤一起倒入铺了豆芽的碗中。

5. **泼油（事件触发）**：在肉片表面均匀撒上剩下的蒜末、干辣椒段(15个)、花椒(1小勺)、葱花。另起锅烧油至 OIL_80(七八成热，油面冒烟)，**将热油均匀泼在辣椒花椒上**——"刺啦"一声，这是**事件触发**！高温热油瞬间激活辣椒和花椒的香气分子，就像事件总线广播了一条高优先级消息，所有消费者(味蕾)同时收到麻辣信号。泼油是整道菜的灵魂，油温不够(事件未触发)就没有灵魂。

6. **完成（返回值）**：立即上桌，麻辣香气四溢，肉片嫩滑、豆芽脆爽。

## 翻车预警（Bug Report）

- ⚠️ **Bug: 肉片发柴、老硬** → 根因：未腌淀粉蛋清 or 煮太久 or 一次性倒入粘连。修复：淀粉+蛋清腌制 15min、逐片下锅、变色即捞（`while 未变色: 煮; 变色: break`）。
- ⚠️ **Bug: 泼油不香、没有"刺啦"声** → 根因：油温不够 or 辣椒花椒被汤汁浸湿。修复：油温必须 OIL_80(七八成热，冒烟)，辣椒花椒撒在肉片表面(不要泡在汤里)，油要均匀泼到所有调料。
- ⚠️ **Bug: 汤底浑浊、豆瓣酱有生味** → 根因：豆瓣酱未炒出红油 or 火太大炒糊。修复：小火慢炒豆瓣酱至红油亮、酱香出，不要炒糊发苦。
