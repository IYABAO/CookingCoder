# 成就系统 🏆

做饭打卡不是白打的，积累成就是继续的动力。

## 积分规则

| 行为 | 积分 |
| --- | --- |
| 完成一次作业（交作业） | +10 |
| 成品有照片 | +5 |
| 复刻新菜谱（不重复） | +5 |
| 自创/改编菜谱 | +10 |
| 记录翻车点并改进 | +5 |

## 运行统计

```bash
# 在仓库根目录运行
python achievements/scripts/stats.py
```

输出：
- 累计作业次数 / 积分
- 连续打卡周数
- 已解锁徽章

## 规则说明

- 作业判定：`homework/week-*.md` 文件存在即算一次
- 照片加分：作业内引用了 `assets/` 图片
- 连续打卡：相邻周数连续（week-36, week-37...）
- 统计是**本地脚本**，跑完把结果贴到 [homework/README.md](../homework/README.md) 的「已交作业」表里
